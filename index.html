A Minecraft to Discord chat
bridge. Quick and easy.

A Minecraft Fabric server mod for 26.3 that sends Minecraft chat to Discord using Webhooks and a built-in bot.

Download Blurpstone Source code Installation guide
Features

Two-way chat, native and clean.

Blurpstone runs a Discord bot inside your Minecraft server process.

Minecraft → Discord

Every player chat message is posted to your channel through a Discord webhook - with the player's username and their skin head as the avatar.

Discord → Minecraft

Messages from real users in the bridged channel are broadcast to everyone online, prefixed with [Discord] and the Discord username.

Self-managed webhook

The bot creates and manages its own webhook the first time it connects - you don't need to generate one manually or hand-craft URLs.

Server-side only

The mod runs entirely on the server. Clients connect with a vanilla client - no install required for players, no version drift to manage.

Installation

Up and running in six steps.

Everything happens on the server side. No client-side mods, no extra processes.

Install Fabric Loader

Install Fabric Loader (≥ 0.19.5) for Minecraft 26.3 on your server.

Add Fabric API

Drop Fabric API into your server's mods/ folder.

Download Blurpstone

Grab the latest blurpstone-<version>.jar from the Releases tab and place it in mods/.

Start the server once

A default config file is generated at config/blurpstone.json.

Fill in the config

Add your bot token, guild ID, channel ID, and Discord user ID - see Configuration.

Restart and go

The bot connects, creates the Blurpstone webhook in the target channel, and the bridge is live.

Discord bot setup

You'll need to create a Discord application and invite it to your server.

Create an application

Head to the Discord Developer Portal and create a new application.

Copy the bot token

Under Bot, copy the token - this goes into botToken.

Enable Message Content Intent

Required so the bot can read chat messages in the bridged channel.

Invite the bot

Give it Read Messages, Send Messages, and Manage Webhooks permissions in your server.

Enable Developer Mode

In your Discord client, so you can right-click servers and channels to copy their IDs.

Configuration

Configuration Setup

The config file lives at config/blurpstone.json inside your server directory and is created automatically on first launch.

config/blurpstone.json 
{
  "botToken": "YOUR_BOT_TOKEN",
  "guildId": "YOUR_SERVER_ID",
  "channelId": "YOUR_CHANNEL_ID",
  "discordOwnerUserId": "YOUR_DISCORD_USER_ID"
}
KeyDescription
botToken The Discord bot token from the Developer Portal.
guildId The ID of the Discord server the bot lives in.
channelId The ID of the text channel to bridge. Both directions use this channel.
discordOwnerUserId Your Discord user ID.
